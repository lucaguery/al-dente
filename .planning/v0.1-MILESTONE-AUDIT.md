## Gaps — Critical Blockers

### GAP-01: `cooking.finalized` event unhandled — partner CookingBanner stuck

**Severity:** HIGH  
**Affected:** COOK-02 (partner banner auto-clear)  
**Files:**
- `frontend/components/RealtimeProvider.tsx` — missing `client.onEvent("cooking.finalized", ...)`
- `frontend/components/HomeDecide.tsx` — missing `COOKING_FINALIZED_DOM_EVENT` listener

**Behavior:** When Luca finalizes a cooking session, the backend broadcasts `cooking.finalized`. The partner's phone never processes this event. The CookingBanner on the partner's phone shows `"En train de cuisiner — Poulet rôti"` indefinitely until they navigate away and back (or force-close the app).

**Fix:**
```typescript
// RealtimeProvider.tsx — add after cooking.started handler
export const COOKING_FINALIZED_DOM_EVENT = "aldente:cooking.finalized";

client.onEvent("cooking.finalized", (payload) => {
  window.dispatchEvent(new CustomEvent(COOKING_FINALIZED_DOM_EVENT, { detail: payload }));
});
```
```typescript
// HomeDecide.tsx — add in the DOM event subscription useEffect
window.addEventListener(COOKING_FINALIZED_DOM_EVENT, () => setActiveLog(null));
return () => window.removeEventListener(COOKING_FINALIZED_DOM_EVENT, () => setActiveLog(null));
```

### GAP-02: Recipe delete crashes backend — TypeError in broadcast_to_household

**Severity:** CRITICAL  
**Affected:** Recipe deletion UX; bonus unlisted realtime event (not in REALTIME-02 scope)  
**File:** `backend/app/routers/recipes.py` line ~635

**Behavior:** `DELETE /recipes/{id}` deletes the recipe from the DB (commit succeeds), then crashes with `TypeError: broadcast_to_household() takes 3 positional arguments but 4 were given` when `db` is passed as a 4th arg. FastAPI returns HTTP 500. The client sees an error toast. The recipe is gone from the DB but the UI thinks the delete failed. The partner's recipe list does not update via WS.

**Fix:**
```python
# Before:
await broadcast_to_household(member.household_id, "recipe.deleted", {"id": str(recipe_id)}, db)
# After:
await broadcast_to_household(member.household_id, "recipe.deleted", {"id": str(recipe_id)})
```
