## Integration Warnings (2)

### MISSING-01: COOK-10 navigation orphan

**Affected:** COOK-10 (Cooking log history)
**Description:** `/cooking-logs` page renders correctly with `OnboardingGuard`, `CookingLogCard`, date-grouped sections, and EmptyState fallback for when the backend `/api/cooking-logs?days=14` endpoint returns 404 (intentionally deferred per Phase 8 budget reality). However, no UI surface links to `/cooking-logs`. Users can only reach the page by typing the URL.

**Fix sketch:** Add a fourth paper-grain Card to Settings (between Foyer and Sauvegarde): "Historique des cuissons" with a `<Link href="/cooking-logs">` CTA. Reuse existing pattern. ~10 LOC.

### REGRESSION-01: COOK-09 SearchInput paper-grain regression

**Affected:** COOK-09 (Recipe library)
**Description:** During Phase 9 UAT, `paper-grain` was removed from SearchInput's wrapper because globals.css's `.paper-grain > * { position: relative }` rule was overriding the absolute Search icon and right-side controls. The fix's comment claimed the parent surface provides the warm-paper backdrop, but on the library page the parent is `bg-background/80 backdrop-blur-sm` (sticky header), not paper-grain. The library SearchInput now reads as plain instead of paper-grain.

**Fix sketch:** Restructure SearchInput so paper-grain is on a sibling absolute layer, not a parent of the icons:

```tsx
<div className="relative">
  <div className="absolute inset-0 paper-grain rounded-xl pointer-events-none" />
  <Search className="absolute left-3 ..." />
  <Input className="pl-10 pr-12 h-12 rounded-xl bg-card relative" />
  <div className="absolute right-2 ...">{controls}</div>
</div>
```

~5 LOC change.
