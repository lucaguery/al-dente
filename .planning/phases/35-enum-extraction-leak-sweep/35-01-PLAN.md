<objective>
ENUM-01 backend half — stop leaking Python `dict` reprs and raw enum keys via `SummaryTurnPayload.chips`.

Purpose: Close the root cause of B-03. The chip-building loop at `backend/app/services/llm.py:927-944` currently does `str(val)` on `extracted_map[field]` — when the field is `ingredients` (a `list[dict]`), this serializes as `{'name': 'riz arborio', 'quantity': 300.0, 'unit': 'g'}` (Python repr, not JSON). The fix: emit structured `{field, value}` payloads and let the frontend formatter own display concerns (per the locked B-03 two-layer fix decision).

Output: New `ChipPayload` Pydantic model; `SummaryTurnPayload.chips` typed as `list[ChipPayload]`; `_run_thread_llm`'s chip loop rewritten to append structured payloads; a new regression test asserting the wire shape. Single atomic commit.
</objective>
