<objective>
Add the `GET /households/{id}/stats` backend endpoint and fully rewrite the Profil page (`/settings`) to the La Grille literal-sketch composition per PROF-01 (D-01 through D-06).

Purpose: Profil is one of the two largest visual regressions in v0.9 — the 3-Card layout reads as Sober Kitchen, not La Grille. The literal-sketch composition (identity line + partner block + stats block + 5 numbered hairline rows) puts /settings in lockstep with Accueil and Bibliothèque, which already shipped this discipline. The stats block needs a small backend endpoint to keep render decoupled from count queries.

Output: One new backend endpoint with 4-test pytest coverage, a complete Profil page rewrite, fr.json key additions, and a Playwright spec validating Card-free DOM + sketch composition.
</objective>
