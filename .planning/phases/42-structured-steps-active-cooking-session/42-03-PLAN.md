<objective>
Add the lazy-backfill endpoint + BackgroundTask that lets the frontend trigger structured-step extraction on first /active visit for recipes whose `steps` is empty or in the legacy flat-string shape.

This plan owns the v0.9 BackgroundTask-pattern reproduction for STEP-03 (D-04..D-07): a new `POST /recipes/{id}/extract-steps` endpoint that mirrors the v0.6 `extract_and_process_url_turn` pattern — returns 202 immediately, schedules a FastAPI `BackgroundTask`, and the BackgroundTask reads turn-0 payload (invariant #5), runs Gemini, persists steps, commits, and broadcasts `recipe.updated` (invariant #4). The frontend (plan 42-04) already subscribes to `recipe.updated` via `RealtimeProvider`, so steps will materialize without further wiring.

A 5-test contract covers the endpoint surface (401 / cross-household 404 / not-found 404 / 202 scheduled / 200 idempotent). A 6th test in `test_invariants.py` asserts the invariant #5 regression — turn-0 payload is byte-identical pre- and post-call.

The endpoint shape `POST /recipes/{id}/extract-steps` was specifically picked over alternatives (PUT on the recipe, POST on /cooking-logs/{id}/active) because it mirrors the existing `POST /recipes/{id}/promote` shape and keeps the side-effect noun (steps) co-located with the resource (recipe). The frontend invokes it on /active mount when the loaded recipe's steps are empty or legacy-shaped.
</objective>

  def extract_and_persist_steps(recipe_id: PyUUID, household_id: PyUUID) -> None:
      """Phase 42 STEP-03 — lazy backfill structured steps for a promoted recipe.

      Mirrors the v0.6 invariant #1 server-side BackgroundTask pattern. Called
      from POST /recipes/{id}/extract-steps. Reads turn-0 payload (invariant
      #5 — never mutated), runs the Gemini structured-extraction prompt against
      the original capture transcript / URL / photo paths, and persists the
      resulting `steps` to the recipe row in the same transaction as the
      `recipe.updated` broadcast.

      No-op if `recipe.steps` already contains structured StepEntry-shaped
      dicts (the router does the idempotency check, but defensive guard here
      protects against duplicate task scheduling under load).

      Caller is responsible for scheduling this via `BackgroundTasks.add_task`
      — do NOT call inline on a request thread (invariant #1).
      """

      from app.db import SessionLocal  # late import to keep module-import safe

      with SessionLocal() as db:
          recipe = db.query(Recipe).filter(Recipe.id == recipe_id).first()
          if recipe is None:
              log.warning(f"extract_and_persist_steps: recipe {recipe_id} not found")
              return

          # Defensive idempotency guard (also enforced by the router).
          if _steps_are_structured(recipe.steps):
              log.info(f"extract_and_persist_steps: {recipe_id} already structured, skipping")
              return

          # Read turn-0 payload — IMMUTABLE per invariant #5.
          turn_zero = (
              db.query(RecipeTurn)
              .filter(RecipeTurn.recipe_id == recipe_id, RecipeTurn.position == 0)
              .first()
          )
          if turn_zero is None:
              log.warning(f"extract_and_persist_steps: {recipe_id} has no turn-0; skipping")
              return

          try:
              # Build a minimal thread payload from turn-0 + the recipe's existing
              # structured fields (title, ingredients) so Gemini has context to
              # reference ingredient names in ingredient_refs.
              thread_payload = _build_steps_extraction_payload(recipe, turn_zero)
              extracted = _run_thread_llm(thread_payload)
              # _apply_extracted writes steps via model_dump per 42-02 Task 4.
              # Reuse it so we don't double-implement the JSON serialization rule.
              _apply_extracted(recipe, extracted)
              db.commit()
          except Exception as exc:
              log.error(f"extract_and_persist_steps failed for {recipe_id}: {exc}")
              # No raise — BackgroundTask exceptions are swallowed by FastAPI.
              # Frontend stays in loading state; user can retry by closing /active
              # and reopening. Productize-later: persist `steps_extraction_error`.
              return

          # Broadcast — invariant #4.
          payload = RecipeResponse.model_validate(recipe, from_attributes=True).model_dump(mode="json")
          broadcast_to_household(household_id, "recipe.updated", payload)
  ```

  from fastapi import BackgroundTasks

  # Response shape — declare a Pydantic model in the router file (small enough,
  # no need to pollute schemas/recipe.py with a router-local DTO).
  class ExtractStepsResponse(BaseModel):
      recipe_id: PyUUID
      scheduled: bool
      reason: str | None = None


  @router.post(
      "/{recipe_id}/extract-steps",
      response_model=ExtractStepsResponse,
      status_code=202,  # default for the scheduled path; 200 override returned via Response below for idempotent path
  )
  def extract_steps(
      recipe_id: PyUUID,
      background_tasks: BackgroundTasks,
      response: Response,
      current_member: Member = Depends(current_member),
      db: Session = Depends(get_db),
  ) -> ExtractStepsResponse:
      """Phase 42 STEP-03 — schedule a BackgroundTask that backfills structured
      steps for a promoted recipe.

      Auth via existing HttpOnly cookie (invariant #8). Cross-household calls
      return 404 to avoid leaking recipe existence. Idempotent: if the recipe
      already has structured steps, returns 200 with reason=already_extracted
      and does NOT schedule a duplicate task.
      """
      from app.services.llm import extract_and_persist_steps, _steps_are_structured

      recipe = db.query(Recipe).filter(Recipe.id == recipe_id).first()
      if recipe is None or recipe.household_id != current_member.household_id:
          # Combined 404 — covers both "not found" and "cross-household" (leak prevention).
          raise HTTPException(status_code=404, detail="recipe not found")

      if _steps_are_structured(recipe.steps):
          response.status_code = 200
          return ExtractStepsResponse(
              recipe_id=recipe.id,
              scheduled=False,
              reason="already_extracted",
          )

      background_tasks.add_task(
          extract_and_persist_steps,
          recipe_id=recipe.id,
          household_id=current_member.household_id,
      )
      return ExtractStepsResponse(
          recipe_id=recipe.id,
          scheduled=True,
          reason=None,
      )
  ```
