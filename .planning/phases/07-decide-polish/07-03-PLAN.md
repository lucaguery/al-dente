      switch (state) {
        case "valide":

    Notes on the helper:
    - **`base` constant** holds the shared pill shape (`inline-flex items-center rounded-full px-2.5 py-0.5 text-sm font-medium h-8 w-fit`). The tokens are `bg-[var(--color-valide-tint)] text-foreground border border-emerald-500/30` (Validé), `bg-primary/15 text-primary border border-primary/40` (Pressenti), `bg-destructive/10 text-destructive/80 border border-destructive/30` (Contesté), `bg-muted text-muted-foreground line-through` (Rejeté), `bg-transparent text-muted-foreground border border-border` (Sans avis).

If the executor's TS config requires a default, add `default: return base;` (no extra tokens) as a safe fallback — but every case should be covered.
