```typescript
export function cookCountToPatina(n: number): PatinaLevel {
  if (n === 0) return 0;
  if (n <= 2) return 1;
  if (n <= 10) return 2;
  return 3;  // cook_count > 10 → patina 3 → dogear renders
}
```

From `backend/app/cli/seed.py`:

- Cooking logs are seeded next (~lines 532-564) for ragu/poulet-citron/burger-classique. For each log, the loop:

  log_count = db.scalar(select(func.count(CookingLog.id)).where(CookingLog.recipe_id == recipe.id)) or 0
