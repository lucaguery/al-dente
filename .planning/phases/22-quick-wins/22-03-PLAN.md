From `frontend/lib/enum-labels.ts`:
```typescript
export function useEnumLabels(): {
  cuisine: (v: string) => string;
  mood: (v: string) => string;
  protein: (v: string) => string;
  season: (v: string) => string;
};
```
Each method takes a wire-format enum string (e.g. `"mediterranean"`) and returns the French label (e.g. `"Méditerranéen"`). Try/catch fallback returns the raw value on missing translation — forward-compat for future enum values.
