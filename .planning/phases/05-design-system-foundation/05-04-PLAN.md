```ts
/**
 * Phase 5 motion language — single source of truth.
 * CSS tokens (`--ease-craft`, `--duration-fast`, `--duration-normal`)
 * defined in `globals.css` @theme block; this module re-exports the
 * same numbers as Framer Motion presets so swipe-deck animations and
 * CSS transitions stay in lockstep.
 */
import type { Transition, Variants } from "framer-motion";

export const easeCraft = [0.32, 0.72, 0.0, 1] as const;

export const durations = {
  fast: 0.15,    // 150ms — interactive feedback
  normal: 0.28,  // 280ms — structural transitions
} as const;

export const transitions = {
  fast: { duration: durations.fast, ease: easeCraft } satisfies Transition,
  normal: { duration: durations.normal, ease: easeCraft } satisfies Transition,
} as const;

export const variants = {
  fadeIn: {
    hidden: { opacity: 0 },
    visible: { opacity: 1, transition: transitions.normal },
  } satisfies Variants,

  slideUp: {
    hidden: { opacity: 0, y: 12 },
    visible: { opacity: 1, y: 0, transition: transitions.normal },
  } satisfies Variants,

  pressFeedback: {
    rest: { scale: 1, transition: transitions.fast },
    pressed: { scale: 0.98, transition: transitions.fast },
  } satisfies Variants,

  swipeCommit: {
    rest: { x: 0, rotate: 0, transition: transitions.normal },
    left: { x: -480, rotate: -8, opacity: 0, transition: transitions.normal },
    right: { x: 480, rotate: 8, opacity: 0, transition: transitions.normal },
  } satisfies Variants,
} as const;
```

Hard constraints:
- The exported names MUST be `easeCraft`, `durations`, `transitions`, `variants` (no renames — Phases 6-9 will import these names directly).
- `easeCraft` MUST be `[0.32, 0.72, 0.0, 1]` — these four numbers must match the cubic-bezier in `globals.css` (Plan 01 Task 2). Any drift breaks the lockstep contract.
- `durations.fast` MUST be `0.15` (seconds, framer-motion convention) corresponding to CSS `--duration-fast: 150ms`.
- `durations.normal` MUST be `0.28` corresponding to `--duration-normal: 280ms`.
- The `satisfies` typing keeps the literal-narrow types (so consumers see `0.15` as a literal, not `number`) while validating against framer-motion's structural types.
- The `as const` assertions on the outer objects ensure read-only literal types end-to-end.

Reduced-motion contract note (from UI-SPEC §Motion "Reduced-motion contract"): the existing `@media (prefers-reduced-motion: reduce)` block in globals.css (lines 254-261) clamps CSS animation/transition durations. The framer-motion side relies on consumers (e.g. swipe-deck in Phase 7) calling `useReducedMotion()` and substituting `instant: true` on commit. THIS PLAN does NOT add any reduced-motion gate to motion.ts — that's a per-consumer concern. Document this in the SUMMARY.

Do NOT add any other exports (no helper hooks, no useReducedMotion wrapper, no animation factory functions). Phase 5 ships the bare contract; downstream phases consume it.
