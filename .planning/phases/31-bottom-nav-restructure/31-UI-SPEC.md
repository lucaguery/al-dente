## Component Specification

### Discriminated Union: `Tab` type

```typescript
// variant: "tab" — flat sibling tab
type FlatTab = {
  variant: "tab";
  href: string;
  pathname: string;          // exact pathname or prefix for active matching
  matchExact: boolean;       // true = pathname ===, false = pathname.startsWith
  icon: LucideIcon;
  labelKey: "home" | "recipes" | "profile";
};

// variant: "central-cta" — elevated capture entry point
type CentralCTA = {
  variant: "central-cta";
  href: string;              // "/recipes/new"
  pathname: string;          // "/recipes/new" — exact match only
  labelKey: "add";
};

type Tab = FlatTab | CentralCTA;
```

The `TABS` const is `ReadonlyArray<Tab>` — 4 entries in left-to-right order.
The render callback switches on `variant` at the top; no conditional spread mid-JSX.
Grep gate: `grep -rn "variant.*tab\|variant.*central-cta" frontend/` must hit the type
definition AND at least one TABS entry.

### Slot Roster (D-01, D-02)

| Slot | href | variant | labelKey | icon | Active predicate |
|------|------|---------|----------|------|-----------------|
| 1 | `/` | `"tab"` | `"home"` | `Home` | `pathname === "/"` |
| 2 | `/recipes` | `"tab"` | `"recipes"` | `BookOpen` | `pathname.startsWith("/recipes") && pathname !== "/recipes/new"` |
| 3 | `/recipes/new` | `"central-cta"` | `"add"` | n/a — `Plus` icon inline | `pathname === "/recipes/new"` |
| 4 | `/settings` | `"tab"` | `"profile"` | `Settings` | `pathname === "/settings" \|\| pathname.startsWith("/settings/")` |

All 4 slots remain `flex: 1` siblings (D-03). No `width: 25%` hardcoding — flex
distribution absorbs a future 5th slot (gh#26) without geometry rework.

### `BottomNav` — nav shell

```
<nav
  aria-label="Navigation principale"
  className="fixed bottom-0 inset-x-0 min-h-[4.5rem] bg-card/85
             backdrop-blur-md border-t border-border flex
             pb-[env(safe-area-inset-bottom)] z-40"
>
```

Changes from current: `min-h-[4rem]` → `min-h-[4.5rem]` (72px). All other
shell classes unchanged (D-04: no notch, no FAB protrusion).

### `variant === "tab"` render branch

```
<Link
  key={href}
  href={href}
  aria-current={active ? "page" : undefined}
  className={`relative flex flex-col items-center justify-center
              flex-1 gap-1 text-xs font-medium
              transition-colors duration-fast ease-craft
              ${active ? "text-primary" : "text-foreground-muted"}`}
>
  {active ? (
    <span
      aria-hidden
      className="absolute inset-x-0 top-2 mx-auto rounded-full
                 h-10 w-10 bg-primary/8 transition-colors
                 duration-fast ease-craft"
    />
  ) : null}
  <Icon size={24} aria-hidden className="relative z-10" />
  <span className="relative z-10">{t(labelKey)}</span>
</Link>
```

Identical to current active-pill idiom. The pill wash (`bg-primary/8`) is
ONLY applied in this branch — never on the CTA branch.

### `variant === "central-cta"` render branch

```
<Link
  key={href}
  href={href}
  aria-label={t("add")}        /* "Ajouter" — accessible name for the circle */
  aria-current={active ? "page" : undefined}
  className="relative flex flex-col items-center justify-center
             flex-1 gap-1 text-xs font-medium
             transition-colors duration-fast ease-craft"
>
  {/* Circle — always filled, always elevated */}
  <span
    aria-hidden
    className={`flex items-center justify-center rounded-full
                bg-primary text-primary-foreground
                w-14 h-14                       /* 56px */
                transition-all duration-fast ease-craft
                active:scale-95                 /* press feedback */
                ${active ? "ring-2 ring-primary/30 ring-offset-1 ring-offset-background" : ""}`}
  >
    <Plus size={24} strokeWidth={2.5} aria-hidden />
  </span>
  {/* Label — same register as siblings */}
  <span className={active ? "text-primary" : "text-foreground-muted"}>
    {t("add")}
  </span>
</Link>
```

**State matrix for the CTA circle:**

| State | Fill | Ring | Scale | Text color |
|-------|------|------|-------|------------|
| Default (inactive) | `bg-primary` (terracotta filled) | none | 1 | `text-foreground-muted` |
| Active (on `/recipes/new`) | `bg-primary` (unchanged — always filled) | `ring-2 ring-primary/30 ring-offset-1 ring-offset-background` | 1 | `text-primary` |
| Pressed (`:active` / tap) | `bg-primary` | as per active state | `scale-95` | as per active state |

The always-filled property is invariant — there is no "inactive visual" for
the CTA circle. D-11: active is additive (ring on top of filled), not transformative.

### `usePathname()` + `useSelectedLayoutSegment()` coexistence

```typescript
// Both hooks live in the same component.
const segment = useSelectedLayoutSegment(); // hide-gate only
const pathname = usePathname();             // active matching for all 4 slots

// Hide check — segment-based (D-10, unchanged behavior)
if (segment?.startsWith("onboarding")) return null;

// Active predicate examples
const isActive = (tab: Tab): boolean => {
  if (tab.variant === "central-cta") return pathname === tab.pathname;
  if (tab.matchExact) return pathname === tab.pathname;
  return pathname.startsWith(tab.pathname) && pathname !== "/recipes/new";
};
```

Critical invariant (D-09): `useSelectedLayoutSegment()` returns `"recipes"` for
BOTH `/recipes` and `/recipes/new`. Using it for active matching would create a
double-active collision. `usePathname()` is the load-bearing fix.

## Interaction Specification

### Tap (primary)

| Slot | Tap behavior |
|------|-------------|
| Flat tab (inactive) | Navigate to `href`; active state transitions `duration-fast ease-craft` |
| Flat tab (active, same route) | No-op navigation (Next.js Link behavior) |
| CTA (inactive) | Navigate to `/recipes/new`; circle gains ring; scale-95 on press |
| CTA (active) | No-op navigation; ring already visible |

### Press feedback

- CTA: `active:scale-95` on the circle span — standard tactile press confirmation.
- Flat tabs: no scale-down (small icon-pill; scale would look jittery). Color
  transition via `transition-colors duration-fast ease-craft` is sufficient.

### Motion (prefers-reduced-motion)

The existing `globals.css` `@media (prefers-reduced-motion: reduce)` rule sets
`animation-duration: 0ms` and `transition-duration: 0ms` globally. Phase 31
inherits this automatically — no new motion guards needed.

### Keyboard / focus

- All 4 nav items are `<Link>` elements — naturally in Tab order.
- `aria-current="page"` on the active link is the WCAG 2.1 landmark pattern
  for current-page indication within a nav region (D-11, D-12).
- Focus ring: existing `outline-ring/50` base style from `globals.css` applies.
  The CTA circle sits inside the `<Link>`, so the focus ring appears around the
  `<Link>` element, not the circle span — this is correct behavior.
- Screen-reader landmark: `aria-label="Navigation principale"` on `<nav>` (unchanged).
