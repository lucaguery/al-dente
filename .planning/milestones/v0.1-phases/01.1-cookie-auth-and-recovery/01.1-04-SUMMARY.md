# Phase 01.1 Plan 04: Frontend Cookie Auth Migration Summary

**One-liner:** Strip Bearer header injection and localStorage token reads from lib/api.ts + lib/ws.ts; replace with `credentials: "include"` and same-origin WS URL; reduce lib/auth.ts to no-op stubs preserving AUTH_TOKEN_CHANGED_EVENT.

## What Was Built

### lib/api.ts
- `fetch()` now uses `credentials: "include"` — browser auto-attaches `aldente_auth` cookie
- No `Authorization: Bearer` header injection (removed)
- On 401: path-conditional `DELETE /api/auth/session` (prod) or `DELETE /auth/session` (dev with `NEXT_PUBLIC_API_BASE` set), wipe legacy localStorage keys, redirect to `/onboarding/welcome`
- `clearLegacyLocalStorage()` exported for external callers
- `NEXT_PUBLIC_API_BASE` still supported for local dev pointing directly at Railway

### lib/ws.ts
- `createRealtimeClient(_legacy?: string)` — token param accepted-but-ignored for compat with `RealtimeProvider.tsx` until Plan 05
- WS URL built from `window.location.origin` (`http→ws`, `https→wss`) — no `?token=` query string
- `NEXT_PUBLIC_WS_BASE` still supported as override for local dev
- On 1008 close: DELETE session, wipe legacy localStorage, redirect to `/onboarding/welcome`
- Reconnect numerals preserved: `minReconnectionDelay: 250`, `maxReconnectionDelay: 5000`, `maxRetries: Infinity`

### lib/auth.ts
- `AUTH_TOKEN_CHANGED_EVENT` export preserved — RealtimeProvider still listens on it
- `clearLocalStorageRemnants()` added — Plan 05 onboarding pages call this after backend sets cookie
- `saveAuthToken()` — no-op stub (dispatches AUTH_TOKEN_CHANGED_EVENT for pre-Plan-05 compat)
- `getAuthToken()` — returns `null` always (RealtimeProvider skips WS open; Plan 05 uses SessionProvider)
- `clearAuth()`, `hasOnboarded()` — no-op stubs marked `@deprecated`
- No `localStorage.getItem` or `localStorage.setItem` calls for `auth_token`

## Deviations from Plan

None — plan executed exactly as written.

The `_legacy?: string` parameter on `createRealtimeClient` was explicitly called for in the plan to prevent RealtimeProvider compile errors until Plan 05. TypeScript compiled cleanly with zero errors across all three tasks.
