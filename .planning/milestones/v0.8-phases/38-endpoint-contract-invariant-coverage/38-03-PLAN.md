<objective>
Land 4-test endpoint contracts for the 5 **infra routers**: `auth_session`, `exports`, `photos`, `push`, `ws`. These routers have varying semantics (auth_session has no household-scoped lookup; ws uses WebSocket close codes instead of HTTP status codes), so the 4-test shape is **adapted per router** as per D-38-05 and CONTEXT.md "Claude's Discretion".

Closes ROUT-02 + ROUT-04 + ROUT-05 + ROUT-09 + ROUT-10. Combined with Plan 38-02's 5 data-router contracts, every router in `backend/app/routers/` now has a contract test file.

**Per-router adaptations (locked):**

- **ROUT-02 auth_session** — endpoints are `DELETE /auth/session` (unauthenticated, idempotent, always returns 200) and `GET /auth/ws-token` (requires cookie OR Bearer; returns `{"token": ...}`). The 4 tests adapt to: (1) DELETE works without auth → 200 with `ok: true`; (2) GET ws-token with Bearer → 200 + token matches seed; (3) GET ws-token without auth → 401; (4) GET ws-token with malformed Bearer prefix → 401 (validation).
- **ROUT-04 exports** — straightforward `GET /households/{household_id}/export.json`. Standard 4-test contract; cross-household uses a path-param `household_id` that doesn't match the seeded member's household_id → 404 (per exports.py:46-49).
- **ROUT-05 photos** — `POST /photos` (multipart upload), `GET /photos/{path}` (signed-URL retrieval). 4-test contract on the upload endpoint (happy with `files=...`; 401 missing auth; 404 cross-household when path points outside household namespace; 422 missing `file` field or wrong content-type).
- **ROUT-09 push** — `POST /push/subscriptions` (subscribe a Web Push endpoint). 4-test contract; validation case asserts `400` for non-https endpoint (push.py:54 — `raise HTTPException(400, "endpoint must be https://")`).
- **ROUT-10 ws** — **D-38-05 close-code adaptation**. Use FastAPI `TestClient.websocket_connect()` as a context manager. (1) Happy: open with `?token=SEED_TOKEN` → connection stays open, no close frame received; (2) Missing auth: open with no token, no cookie → `WebSocketDisconnect` raised with `code == 1008` (status.WS_1008_POLICY_VIOLATION per ws.py:53); (3) Invalid auth: open with `?token=garbage` → close with code 1008 (ws.py:63); (4) Malformed-frame validation: send a frame and verify the server silently discards it (per ws.py:78-79 — "If a client sends a frame we silently discard it") — there is no separate close code for malformed frames in the current router, so the test asserts the connection stays open after `send_text("garbage")` rather than failing.

Purpose: complete the router-contract sweep so every router has a regression net before Plan 38-04 starts the invariant tests.
Output: 5 new test files; ROUT-02/04/05/09/10 closed.

**WebSocket testing pattern with TestClient:**

    from fastapi import WebSocketDisconnect

    with client.websocket_connect("/ws?token=SEED_TOKEN") as ws:
        # Stays open — happy path. No assertion needed beyond context manager not raising.
        pass

    # 401-equivalent:
    with pytest.raises(WebSocketDisconnect) as excinfo:
        with client.websocket_connect("/ws") as ws:
            ws.receive_text()  # forces a read so the close frame is observed
