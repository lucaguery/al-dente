<objective>
Land 4-test endpoint contracts for the 5 **data routers**: `households`, `recipes`, `cooking_logs`, `votes`, `shortlist`. Each router gets one new `test_<name>_contract.py` file with exactly four test functions (or four parametrized cases — planner-discretion per CONTEXT.md):

1. **Happy path** — authenticated request to the primary endpoint of the router returns 2xx.
2. **401 missing/invalid auth** — same request with no auth (or invalid token) returns 401.
3. **404 cross-household** — request with valid auth but targeting a resource owned by a DIFFERENT household returns **404** (NOT 403 — D-38-02 / CLAUDE.md cross-household isolation pattern; 403 would leak existence).
4. **Validation failure** — malformed payload (bad UUID, missing required field, wrong enum value, out-of-range value) returns 422 (or 400 where the route uses explicit `HTTPException(400, ...)` like votes.py:50).

Closes ROUT-01 + ROUT-03 + ROUT-06 + ROUT-07 + ROUT-08. Coverage on these 5 router files should climb from the post-37 baseline (~48-66%) toward the 80%+ range that Plan 38-04 needs to hit COV-01 (≥85% repo total).

Purpose: drive router files from spotty coverage to dependable contract coverage; lock the cross-household isolation invariant against accidental 403 leaks.
Output: 5 new test files, ~20 new tests, suite remains green.
