    - `coverage.json` not found is a hard FAIL with TESTING.md pointer to the `pytest --cov-report=json:coverage.json` command.
    - Script exits 0 on success, 1 on any failure. CI invokes via `python scripts/check_rules_files_coverage.py backend/coverage.json`.
  </behavior>
  <action>

    Structure:
    1. Module docstring referencing CI-02, D-39-03, and the 4 rules files by absolute name.
    2. Module constant `RULES_FILES = ("app/services/voting.py", "app/services/algorithm.py", "app/services/shortlist.py", "app/auth.py")`. Order is fixed; do not sort alphabetically — keep the order from REQUIREMENTS.md COV-02..05 for output consistency.

The script must match that convention.
