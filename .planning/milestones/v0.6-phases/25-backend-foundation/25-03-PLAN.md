<objective>
Cut the frontend over to the new API shape that Plan 02 exposed. Remove `source_capture` from the `Recipe` type, replace with `initial_turn_kind`, rewrite the one component that read `recipe.source_capture?.type` (RecipeDraftCard), and update e2e test fixtures + assertions. This is the cleanup that closes the Phase 25 cutover end-to-end.

This plan keeps frontend + backend in lockstep through the cutover, satisfying THREAD-02 ("every reader rewritten in the same change").

Output: Updated `Recipe` type, rewritten `RecipeDraftCard`, comment cleanup in three other files, four e2e specs updated. Frontend TypeScript and Playwright tests pass against the cut-over backend.
</objective>
