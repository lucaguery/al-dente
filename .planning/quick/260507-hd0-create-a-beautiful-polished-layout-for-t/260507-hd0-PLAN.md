<design_principles>
<!-- Reference frame for the executor. The plan does NOT prescribe pixel-exact decisions; it prescribes a coherent system within these guardrails. -->

1. **One accent, many tints.** Brand rose stays the only accent. Derive a tint scale (e.g., rose-50 / rose-100 / rose-600) instead of introducing a second hue.
2. **4-pt spacing grid.** Use Tailwind's default scale (1, 2, 3, 4, 5, 6, 8, 10, 12) which already maps to 4-pt increments. Avoid arbitrary values like `gap-[11px]`.
3. **Typography hierarchy.** Define and use 4 sizes: display (~32–34/tight), title (~20–22), body (~16), caption (~13–14). Map these to utility classes in globals.css so all screens converge.
4. **Depth via shadow + border, not color.** Cards rest on bg-card with a hairline border and a soft single-layer shadow. No competing elevations.
5. **Safe-area first.** Top safe-area in body, bottom safe-area in BottomNav (already done — preserve). Use min-h-dvh on the html or main for correct iOS Safari sizing.
6. **Premium micro-feel.** Subtle backdrop-blur on BottomNav so content scrolls underneath gracefully. Active states use opacity + transform (translate-y-px on press), never color flashes.
7. **Reduced-motion respected.** Already global — do not bypass with inline animations.
8. **i18n first.** Every new string goes through next-intl. No hardcoded French in JSX.
</design_principles>
