<objective>
Harmonize typography and spacing across every frontend page so all surfaces converge on a single page container, section rhythm, and heading scale. The codebase already has a partial type scale (`.text-display` / `.text-title` / `.text-body` / `.text-caption` in `globals.css`) but lacks shared **spacing tokens** — every page hardcodes `px-6` / `pt-6` / `pb-24` (or `pb-32`) on its own, and the recipes library page uses the divergent `px-4` with a desktop 4-column grid. Output: 4 spacing tokens added to `@theme` + a coordinated sweep across 14 page files + 2 heavy-content components, with no behavior changes and no string changes.
</objective>
