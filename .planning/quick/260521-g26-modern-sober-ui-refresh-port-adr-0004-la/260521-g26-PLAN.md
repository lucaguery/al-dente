frontend in 5 atomic waves: tokens → shared components → screens → logo + icons →
cleanup. After wave 5 there is no remaining trace of the Sober Kitchen register
(Cormorant + Caveat + IBM Plex + paper-grain + patine + warm-brown shadows + ledger
cards + marginalia + pasta-strand icon).

**Purpose.** Partner test on 2026-05-20 read Sober Kitchen as "old, something for
old people". The information architecture (date → hero → list → CTA → nav) is
intact; only the visual expression of sobriety changes. La Grille · Soft warmth
was validated on 2026-05-21.

drops, logo geometry, bottom nav contract, and member-color treatment are
**locked in `docs/adr/0004-modern-sober-refresh.md`**. The executor MUST quote the
ADR section, NOT re-derive. ADR §Considered Alternatives lists 11 rejected
directions — do not re-litigate.

(`cd frontend && npm run lint && next build --webpack`) and the e2e smoke
(`npx playwright test --grep @smoke`) must pass. Visual delta is expected; layout
delta is not.

**Mode lock.** Per `CLAUDE.md` "MVP phase posture": no backward-compat shims, no
v1/v2 stubs, no "both paths live". Drop dead classes/files in the **same** commit
as their replacement. Single migration per concern.

entry, `SPEC.md` inline banner, and `frontend/CLAUDE.md` design-token pointer
are tracked separately — see TODO note at end of file.
