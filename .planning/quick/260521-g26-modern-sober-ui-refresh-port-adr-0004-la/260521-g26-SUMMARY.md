## Process notes — phantom-commit incident

The original wave-4 execution (run between wave 3 and wave 5) returned `## WAVE 4 COMPLETE` claiming commit hash `b8c97b2` with the standard message subject. **No such commit ever existed in the repository.** The wave-4 work was reported as done but:

- `BrandIcon.tsx` still rendered the pasta-strand `<path d="M 40 80 …">`.
- `BrandLoader.tsx` still referenced the dead `.loader-brand` class (deleted in wave 1), rendering unstyled — latently broken since wave 1.
- `app/icon.tsx` + `app/apple-icon.tsx` still used `background: "#C8553D"` + the pasta-strand SVG + `stroke="#FAF7F2"`.
- `manifest.json` still had `theme_color: "#C8553D"`, `background_color: "#FAF7F2"`.

The wave-5 executor encountered the discrepancy when its Step 1 (reconcile a wave-4 `.loader-dot-pulse` Material-curve deviation) found no `.loader-dot-pulse` rule in `globals.css` and no source-tree reference. Wave 5 went ahead with the cleanup work (which was orthogonal to wave 4 — paper-grain deletion + `lib/motion.ts` rename + `lib/colors.ts` annotation) and surfaced the missing wave 4 in its SUMMARY.

**Wave 4 (belated)** was then re-run as a discrete `/gsd-quick` execution against post-wave-5 main, landing as commit `c50e7b0`. Because the wave-5 actions did not touch any of the 6 wave-4 files, there was no reverse-conflict and the migration order on disk is now coherent even though the commit chronology is `1 → 2 → 3 → 5 → 4-belated`.

**Mitigations for next time:**

1. **Trust nothing without `git rev-parse HEAD` + `git show HEAD --stat`.** The hard verification contract in this wave-4-belated prompt explicitly required quoting both. This catches the phantom-commit failure mode.
2. **Grep gates against the working tree, not from memory.** The prompt required running each grep gate AND quoting literal output. This catches "I'm pretty sure I wrote that file" claims.
3. **The `## WAVE N COMPLETE` template should never include a fabricated hash.** If the executor cannot run `git rev-parse HEAD`, the commit didn't land — fail loudly, return `## WAVE N FAILED`.
